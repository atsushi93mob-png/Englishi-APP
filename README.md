# 🌱 フォーカス・タイマー・ガーデン

集中するたびに、あなただけの庭に植物が育っていく **ポモドーロ・タイマー** です。
1つの HTML ファイルだけで動作し、サーバーもビルドも不要です。

## ✨ 特徴

- **ポモドーロ・タイマー** — 集中25分 / 小休憩5分 / 長休憩15分をワンタップで切り替え
- **育つ庭** — 集中セッションを完了するたびに、花・茂み・木などの植物が1つ増えます
- **タスク連携** — 「今取り組むこと」を入力しておくと、育った植物にタスク名と日時が記録され、植物にマウスを重ねると確認できます
- **統計** — 「今日の集中」「植えた総数」「連続日数」を記録
- **週間グラフ** — 直近7日間の集中回数を棒グラフで表示（今日はハイライト表示）
- **設定パネル** — 集中/休憩の長さ、完了サウンド、デスクトップ通知、自動開始をカスタマイズ（⚙ボタン）
- **ライト / ダークテーマ** — 右上のボタンでいつでも切り替え。選択は保存されます
- **デスクトップ通知** — セッション完了をブラウザ通知でお知らせ（設定でON、要許可）
- **自動データ保存** — 記録・設定はブラウザの `localStorage` に保存され、次回もそのまま続きから
- **完了サウンド** — セッション終了時に心地よい和音でお知らせ
- **オフライン動作** — 外部通信・依存ライブラリなし。ファイルを開くだけ

## 🚀 使い方

1. `index.html` をブラウザ（Chrome / Edge / Firefox など）で開きます
2. （任意）「今取り組むこと」にタスク名を入力します
3. 上部のタブでモード（集中 / 休憩）を選びます
4. **スタート** を押して集中を始めます
5. 集中セッションを完了すると、庭に植物が1つ育ちます 🌱
6. 育った植物にマウスを重ねると、そのとき取り組んだタスクと日時が表示されます

> データはお使いのブラウザ内にのみ保存されます。別のブラウザや端末とは共有されません。

### ⌨️ ショートカット

| キー | 動作 |
|------|------|
| `Space` | スタート / 一時停止 |
| `Esc` | 設定パネルを閉じる |

### 🔘 ボタン

| ボタン | 動作 |
|--------|------|
| スタート | タイマーの開始・一時停止・再開 |
| リセット | 現在のモードの時間を初期値に戻す |
| スキップ | 現在のセッションを完了扱いにする |
| ☀️ / 🌙 | ライト / ダークテーマの切り替え |
| ⚙ | 設定パネル（時間・サウンド・通知・自動開始）を開く |
| 庭をリセット | すべての植物と記録を削除（設定は保持 / 元に戻せません） |

## 🛠 技術

- 単一ファイルの HTML / CSS / バニラ JavaScript
- 植物のグラフィックは、保存されたシード値から SVG で決定論的に生成
- ビルドツール・依存パッケージ・ネットワーク通信なし
