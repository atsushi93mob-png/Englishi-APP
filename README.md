# 🗣️ はじめての英会話

シーン別に「聞いて・話して」覚える、**初心者向けの英会話アプリ**です。
1つの HTML ファイルだけで動作し、サーバーもビルドも不要です。

> 🌱 このリポジトリには、おまけとして **ポモドーロ・タイマー**（`focus-timer.html`）も同梱しています（[下記参照](#-おまけフォーカスタイマーガーデンfocus-timerhtml)）。

## ✨ 特徴

- **シーン別フレーズ** — あいさつ／自己紹介／カフェ・レストラン／買い物／旅行・道案内／日常会話／困ったとき／ビジネス／時間・数字／天気・季節／体調・病院／気持ちを伝える の **12カテゴリ・全72表現**
- **発音を聞く** — 🔊 ボタンでブラウザの読み上げ機能により英語の発音を再生（カタカナ読みガイド付き）
- **🎤 発音チェック（音声認識）** — マイクに向かって話すと、認識結果と英文を単語ごとに照合し、100点満点でスコア表示。合っていた単語は緑、違った単語は赤で表示（高得点なら自動で「覚えた」に）
- **会話例** — 各シーンのミニ会話（ダイアログ）で自然な流れを確認
- **💬 英語で会話の練習（ロールプレイ）** — 相手からの簡単な英語の質問に、マイクに向かって英語で答える練習。答えは音声認識され、キーワードで「伝わったか」をフィードバック。お手本の答えも表示・再生できます
- **4択クイズ（2モード）**
  - **📖 意味から選ぶ** — 日本語の意味に合う英語表現を選ぶ
  - **🎧 リスニング** — 英語の音声だけを聞いて、正しい意味を選ぶ
  - どちらも全10問。覚えた表現がたまるほど出題対象が広がります
- **🐢 音声の速度切替** — 読み上げを「ゆっくり／ふつう／はやい」から選べます
- **🎯 1日の目標＆デイリー進捗** — 「今日の学習」回数を目標（5〜30）に対してバー表示。達成でお祝いバッジ 🎉
- **🌗 テーマ切替** — ライト／ダーク／自動（端末設定に追従）
- **📥 データのバックアップ** — 学習記録を JSON ファイルに書き出し・読み込み。別の端末やブラウザに引き継げます
- **進捗の記録** — 「覚えた表現」「連続学習日数」を `localStorage` に自動保存
- **オフライン動作** — 外部通信・依存ライブラリなし（発音チェック・会話・リスニングはブラウザの音声機能を使用）

## 🚀 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari 推奨）で開きます
2. 上部のタブで **📚 学ぶ** / **💬 会話** / **✏️ クイズ** / **⚙️ 設定** を切り替えます
3. **学ぶ**：カテゴリを選び、フレーズを 🔊 で聞く・🎤 で発音チェック。覚えたら「覚えた」ボタンで記録
4. **会話**：英語の質問に 🎤 で英語で答える練習。「お手本を見る」で模範解答を確認
5. **設定**：音声速度・テーマ・1日の目標の変更、記録の書き出し／読み込みができます

> データはお使いのブラウザ内にのみ保存されます。別のブラウザや端末とは共有されません。

### 🎤 発音チェック・リスニングについて

- 発音チェックはマイクの許可が必要です。**Chrome / Edge / Safari** を推奨します。
- ブラウザの音声認識・読み上げ機能を利用します。`file://` で直接開くとマイクが使えないことがあるため、公開URL（`https://`）または `localhost` 経由での利用を推奨します。

## 🌐 ネット公開（GitHub Pages）

このアプリは静的な HTML なので、**GitHub Pages** でそのまま公開できます。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** で「Deploy from a branch」を選ぶ
3. **Branch** を `main` ／ フォルダを `/ (root)` にして **Save**
4. 数十秒〜数分後、`https://<ユーザー名>.github.io/focus-timer-garden/` で公開されます
   （このリポジトリの場合：`https://atsushi93mob-png.github.io/focus-timer-garden/`）

トップページ（`index.html`）が英会話アプリ、`/focus-timer.html` がタイマーになります。

## 🛠 技術

- 単一ファイルの HTML / CSS / バニラ JavaScript
- 音声再生は Web Speech API（`speechSynthesis`）、発音チェックは音声認識（`SpeechRecognition`）
- ビルドツール・依存パッケージ・外部ネットワーク通信なし

## 🌱 おまけ：フォーカス・タイマー・ガーデン（`focus-timer.html`）

集中するたびに、あなただけの庭に植物が育っていく **ポモドーロ・タイマー** です。

- **ポモドーロ・タイマー** — 集中25分 / 小休憩5分 / 長休憩15分をワンタップで切り替え
- **育つ庭** — 集中セッションを完了するたびに、花・茂み・木などの植物が1つ増えます
- **統計** — 「今日の集中」「植えた総数」「連続日数」を記録
- **自動データ保存** — 記録はブラウザの `localStorage` に保存
- **オフライン動作** — 外部通信・依存ライブラリなし

`focus-timer.html` をブラウザで開くか、公開後は `/focus-timer.html` にアクセスしてください。
`Space` キーでスタート / 一時停止できます。
