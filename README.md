# 🌱 フォーカス・タイマー・ガーデン

集中するたびに、あなただけの庭に植物が育っていく **ポモドーロ・タイマー** です。
1つの HTML ファイルだけで動作し、サーバーもビルドも不要です。

---

## 🗣️ おまけ：はじめての英会話（`english-conversation.html`）

初心者向けの **英会話アプリ** も同梱しています。こちらも単一 HTML ファイルで、
ブラウザで `english-conversation.html` を開くだけで使えます。

- **シーン別フレーズ** — あいさつ／自己紹介／カフェ・レストラン／買い物／旅行・道案内／日常会話／困ったとき／ビジネス の8カテゴリ、全48表現
- **発音を聞く** — 🔊 ボタンでブラウザの読み上げ機能により英語の発音を再生（カタカナ読みガイド付き）
- **会話例** — 各シーンのミニ会話（ダイアログ）で自然な流れを確認
- **4択クイズ** — 日本語の意味に合う英語表現を選ぶ全10問。覚えた表現がたまるほど出題対象が広がります
- **進捗の記録** — 「覚えた表現」「連続学習日数」を `localStorage` に自動保存
- **オフライン動作** — 外部通信・依存ライブラリなし

---

## ✨ 特徴

- **ポモドーロ・タイマー** — 集中25分 / 小休憩5分 / 長休憩15分をワンタップで切り替え
- **育つ庭** — 集中セッションを完了するたびに、花・茂み・木などの植物が1つ増えます
- **統計** — 「今日の集中」「植えた総数」「連続日数」を記録
- **自動データ保存** — 記録はブラウザの `localStorage` に保存され、次回もそのまま続きから
- **完了サウンド** — セッション終了時に心地よい和音でお知らせ
- **オフライン動作** — 外部通信・依存ライブラリなし。ファイルを開くだけ

## 🚀 使い方

1. `index.html` をブラウザ（Chrome / Edge / Firefox など）で開きます
2. 上部のタブでモード（集中 / 休憩）を選びます
3. **スタート** を押して集中を始めます
4. 集中セッションを完了すると、庭に植物が1つ育ちます 🌱

> データはお使いのブラウザ内にのみ保存されます。別のブラウザや端末とは共有されません。

### ⌨️ ショートカット

| キー | 動作 |
|------|------|
| `Space` | スタート / 一時停止 |

### 🔘 ボタン

| ボタン | 動作 |
|--------|------|
| スタート | タイマーの開始・一時停止・再開 |
| リセット | 現在のモードの時間を初期値に戻す |
| スキップ | 現在のセッションを完了扱いにする |
| 庭をリセット | すべての植物と記録を削除（元に戻せません） |

## 🛠 技術

- 単一ファイルの HTML / CSS / バニラ JavaScript
- 植物のグラフィックは、保存されたシード値から SVG で決定論的に生成
- ビルドツール・依存パッケージ・ネットワーク通信なし
